# IndiHome Field - PHP

Aplikasi pencatatan pekerjaan teknisi berbasis PHP dan SQLite.

## Menjalankan

```powershell
cd php-app
C:\xampp\php\php.exe -S localhost:8000
```

Buka `http://localhost:8000`.

## Akun awal

- Pimpinan: `admin` / `admin123`
- Teknisi: `andi` / `teknisi123`
- Teknisi: `rizky` / `teknisi123`

Database dibuat otomatis di `data/indihome-field.sqlite` saat aplikasi pertama kali dibuka.
